# 實機驗證清單

- 用途：發行前在實機以預覽版（例如 2.0.0-rc.1）逐項驗證 CI 無法涵蓋的項目。結果填入「結果」欄
  （Passed／Failed／Skipped／Not Tested，定義見 [Testing-Plan](Testing-Plan.md)），Failed 請附說明或截圖，
  完成後更新 [Hardware-Compatibility](Hardware-Compatibility.md) 的「實機狀態」。
- 建議至少兩台：**Windows 11 繁體中文**（主要）與 **Windows 10 22H2**；有 NVIDIA 顯示卡、有熱區的筆電各一台更好。
- 每台先記錄環境：

| 項目 | 電腦 1 | 電腦 2 |
|---|---|---|
| Windows 版本／組建、語系 | | |
| CPU、RAM | | |
| 顯示卡（NVIDIA 驅動版本） | | |
| 磁碟（SSD／HDD、USB） | | |
| 網路（乙太網路、Wi-Fi、VPN） | | |
| 螢幕縮放比例 | | |

## A. 安裝與啟動

| # | 步驟 | 預期結果 | 結果 |
|---|---|---|---|
| A1 | 以 `Get-FileHash` 核對 zip 的 SHA-256 | 與 Release 頁面相同 | |
| A2 | 解壓縮到一般資料夾，執行 `PerformanceMonitor.exe` | SmartScreen 警告可按「其他資訊 → 仍要執行」開啟；記錄第一次啟動秒數 | |
| A3 | 第二次啟動 | 比第一次快；記錄秒數 | |
| A4 | 防毒軟體（Windows Defender 或其他） | 沒有被隔離或刪除；如有警告請記錄名稱 | |
| A5 | 以一般使用者（非系統管理員）執行 | 所有功能正常，不要求提升權限 | |

## B. 資料來源（與工作管理員或廠商工具比對）

| # | 步驟 | 預期結果 | 結果 |
|---|---|---|---|
| B1 | CPU：閒置與壓力（例如開大量瀏覽器分頁） | 與工作管理員「效能」頁趨勢一致（短時間差異數 % 內） | |
| B2 | 記憶體 | 總量、已用與工作管理員一致 | |
| B3 | 磁碟容量：C: 與其他固定磁碟；插拔 USB 固定磁碟 | 數值與檔案總管一致；插拔後新增或移除，不會當掉 | |
| B4 | 磁碟 I/O：複製大檔案 | 讀寫 MB/s、忙碌率與工作管理員趨勢一致；邏輯與實體磁碟都有數值 | |
| B5 | NVIDIA GPU：閒置與 3D／影片負載 | 使用率、顯存、溫度與 `nvidia-smi` 或工作管理員一致；沒有 NVIDIA 的電腦顯示「無法使用」 | |

| B7 | ACPI 熱區（筆電） | 有熱區時有溫度且合理；沒有時顯示「無法使用」；畫面與報告不稱 CPU 溫度 | |
| B8 | 程序 | 前 N 名與工作管理員「詳細資料」的記憶體（工作集）一致 | |
| B9 | **繁體中文 Windows** | CPU、磁碟 I/O、熱區都有數值（使用英文計數器名稱，不受語系影響） | |

## F. 穩定性與主控台

| # | 步驟 | 預期結果 | 結果 |
|---|---|---|---|
| F1 | `pwsh .\tools\Test-Stability.ps1 -Target Cli -Cli <路徑>\PerformanceMonitor.Cli.exe`（24 小時） | 報告「通過」；記錄 CPU 平均、Private Bytes 開始／結束與趨勢 | |
| F2 | `-Target App -App <路徑>\PerformanceMonitor.exe -Cli <路徑>\PerformanceMonitor.Cli.exe -DurationMinutes 1440` | 同上 | |
| F3 | `PerformanceMonitor.Cli.exe run` 後按 Ctrl+C | 正常停止，Log 有「監控正常停止」、CSV 可開啟 | |
| F4 | `PerformanceMonitor.Cli.exe report --from <日期> --to <日期>` | 產生報告並顯示摘要 | |

> 穩定性工具需要 PowerShell 7 與原始碼中的 `tools` 資料夾（不在 zip 內）。
